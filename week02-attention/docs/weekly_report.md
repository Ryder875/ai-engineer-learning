## 2. 实验与结论

固定种子 42，SGD，学习率 0.1，训练/验证/测试划分为 360/120/120；本周未使用测试集。

| Batch size | Epochs | 参数更新次数 | 验证 loss | 验证准确率 |
|---:|---:|---:|---:|---:|
| 360 | 200 | 200 | 0.6056 | 85.00% |
| 32 | 200 | 2400 | 0.0945 | 99.17% |
| 360 | 2400 | 2400 | 0.0946 | 99.17% |

相同 epoch 数下，mini-batch 本次表现更好；相同更新次数下，两者验证表现接近，但累计处理样本数不同。单次实验且未计时，不能推广为普遍优劣或速度结论。详见 experiment.md。

## 3. 核心理解

1. Epoch、更新次数和实际耗时是不同的比较条件；backward 累加梯度，step 更新参数但不清空梯度。
2. Q、K 决定匹配分数和汇总权重，V 提供信息；weights @ V 等价于对各 value 向量加权求和。
3. Causal mask 在 softmax 前将未来位置分数设为负无穷，使未来权重为零。修改未来 token 后，过去位置的输出保持不变。
4. 最终 loss 的梯度能传回生成 Q、K、V 的三个线性层，参数更新已验证。
