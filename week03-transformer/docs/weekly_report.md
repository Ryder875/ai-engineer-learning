## 3. 我的理解

通过本周问答，能够解释：

1. 拆头与合头的轴变化，scores 的 query/key 含义，以及 softmax 的归一化方向。
2. causal mask 限制未来访问；堆叠 block 时还需保证前层及其他模块不泄露未来信息。
3. 残差相加保留输入并学习修正；LayerNorm 对每个 token 的特征独立计算统计量。
4. FFN 不直接混合位置，但能加工 Attention 已汇总的上下文信息。
5. Embedding 参数量、位置表示、logits、错位目标，以及交叉熵中忽略标签的作用。
6. 单看高准确率不足以证明模型利用上下文，可以通过权重观察与消融对照检查解释。
